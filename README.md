# Building Detection with EO and AI

Finding new buildings from satellite data, so that a person checks as few places as possible and most of
them turn out to be real.

> **Status:** work in progress. This repository holds the project's public documentation. The code will be
> published here when it is ready.

## What the project does

Municipalities keep a register of buildings, and keeping it up to date means finding what has been built
since the last survey. This project tests whether Earth observation (EO) data — satellite radar and optical
imagery — combined with machine learning can point to the places where something new has been built, so that
the register can be updated from a short list of checks instead of a full new survey.
